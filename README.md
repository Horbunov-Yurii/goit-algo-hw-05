Висновок

Під час виконання завдання було реалізовано та порівняно три алгоритми пошуку підрядка в тексті: Boyer–Moore, Knuth–Morris–Pratt (KMP) та Rabin–Karp.

Для тестування використовувалися дві текстові статті різного розміру. Для кожної статті перевірялися два сценарії: пошук підрядка, який присутній у тексті, та пошук підрядка, якого в тексті немає.

Для вимірювання продуктивності використовувалася бібліотека timeit. Кожен алгоритм виконував пошук 1000 разів для кожного тестового випадку.

За результатами тестування алгоритм Boyer–Moore показав найкращу швидкодію в усіх чотирьох випадках. Його загальний час виконання становив 0.000573760 секунди, тоді як KMP — 0.002887005 секунди, а Rabin–Karp — 0.007511350 секунди.
